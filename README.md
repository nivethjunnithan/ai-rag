# 🔍 RAG (Retrieval-Augmented Generation) From Scratch

Large Language Models (LLMs) are trained on vast datasets, but their knowledge is fixed at training time. This makes it difficult for them to reason about recent updates or private information. Fine-tuning is one approach to address this limitation, but it's often expensive and not ideal for retrieving factual data.

Retrieval-Augmented Generation (RAG) is a powerful technique that enhances an LLM's capabilities by allowing it to fetch relevant documents from external sources and use them as context during generation. This helps the model produce more accurate and up-to-date responses without needing retraining.

This project provides a step-by-step walkthrough of RAG fundamentals — covering document indexing, retrieval mechanisms, and integrating these with generative models — through code and notebooks.
